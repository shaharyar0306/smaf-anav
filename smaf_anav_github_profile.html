Static Malware Analysis Automation Framework — v1.0
Python 3.8+ Windows TrID | strings | FLOSS MIT License Active
🔍 Overview

Python-based static malware analysis automation — runs PE executables through a multi-tool pipeline to extract actionable threat intelligence without executing the malware.

✨ Features
🔎
File Type Detection
TrID signature matching with confidence %
📝
String Extraction
ASCII + Unicode via strings.exe
🔓
FLOSS Deobfuscation
Stack & decoded string recovery
🧬
Malware Family ID
IOC signature database matching
🌐
URL Detection
Embedded URLs & domains flagged
📊
Dual Reports
HTML + TXT output generated
🚀 Usage
# Run the analyzer
python analyzer.py TotalAware2.exe
